三种协议分别怎么填地址

OpenAI 兼容：填到域名，例如 https://api.openai.com；系统补 /v1/chat/completions，用 Authorization: Bearer。

Claude：填到域名或中转站给的 /v1/messages，例如 https://api.anthropic.com。系统补 /v1/messages，用 x-api-key + anthropic-version。浏览器直连会带 anthropic-dangerous-direct-browser-access（官方要求，不带会被拒）。
⚠️ Anthropic 官方对部分地区返回 403 Request not allowed，国内请用支持 Claude 的中转站。

Gemini：可填根地址（系统拼 /v1beta/models/模型:streamGenerateContent?alt=sse），也可以把中转站给的带 {model} 占位符的完整地址整条贴进来，例如 https://host/v1beta/models/{model}:generateContent —— 占位符会自动替换，流式地址也会自动切换。

                             没声音？看看这几条排查建议
                            
    
                                
  • 端点别带 /v1/chat/completions：那会被当成「Chat 音频输出」格式，模型必须真的支持输出音频才会成功。
    • 
                                
  • HTTP 地址只能是本机：浏览器安全策略禁止网页请求外站 http，写 https:// 或 http://127.0.0.1:端口。
    • 
                                
  • 服务端要允许跨域（CORS）：本地服务需加 --enable-cors-header 或等价配置，否则报错是「无法连接」。
    • 
                                
  • 模型名与声音名要对上：例如 OpenAI 是 tts-1 + alloy，火山是 voice_type，ElevenLabs 要 voice id。
    • 
                                
  • 点「试听」看回显：它会告诉你实际试了哪几种格式、分别为什么失败。
    •

 语音转文字（STT）

                        

                            配置端点与识别模型后，语音输入按钮会改为「点一下录音、再点一下结束」，录音上传到此接口转成文字填进输入框——浏览器自带识别不可用或不好使（夸克等）时就靠它。
                            保存后立即生效；清空并保存即恢复浏览器原有行为。端点只需填到服务根地址（例如 https://api.openai.com），系统会自动补 /v1/audio/transcriptions。
                        

                        

                            
                            
                            

                                接口需兼容 OpenAI /v1/audio/transcriptions（whisper-1、gpt-4o-transcribe、本地 FunASR/whisper 服务等）。
