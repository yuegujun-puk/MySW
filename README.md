📱 My SW - 搞基 AI 角色扮演聊天应用<br>
这是一个功能丰富的单文件 HTML 聊天应用，专为 AI 角色扮演对话设计。整个应用完全运行在浏览器端，无需后端服务器。<br>
🎨 核心特性<br>
1. 精美的 UI 设计<br>
深色主题：采用深灰/黑色调 (#1a1c23, #262933)，搭配金色强调色 (#e6c78a)<br>
动态背景：支持自定义聊天背景图片，带半透明遮罩层<br>
响应式布局：完美适配移动端和桌面端，支持视图切换<br>
流畅动画：消息淡入、悬停效果、平滑过渡等<br>
2. 多角色管理系统<br>
预设角色：内置多个角色（银狼、昔涟、叶瞬光、阮梅等）<br>
自定义角色：可创建、编辑、删除自定义角色，设置名字、头像、System Prompt<br>
角色分组：支持好友分组管理，可折叠/展开<br>
置顶功能：重要联系人可置顶显示<br>
备注功能：可为角色设置个性化备注名<br>
3. 强大的 AI 对话功能<br>
API 配置：支持自定义 AI API 地址、API Key、模型名称<br>
System Prompt：每个角色有独立的人设提示词<br>
Markdown 渲染：使用 Marked.js 解析 Markdown 格式回复<br>
多模态支持：可发送图片（可选是否计入上下文）<br>
快速回复：AI 生成建议回复选项<br>
4. 多对话线程管理<br>
每个角色支持多个独立对话线程<br>
可创建、切换、重命名、删除线程<br>
各线程拥有独立的聊天记录和长期记忆<br>
5. 主动关怀模式<br>
AI 可主动发起对话关怀用户<br>
支持结合角色性格生成关怀语<br>
关怀消息带有特殊样式标识<br>
6. 数据管理<br>
本地存储：所有数据保存在 localStorage<br>
完整导出/导入：<br>
导出所有设置、角色、聊天记录为 JSON<br>
一键导入备份恢复数据<br>
角色单独导出/导入：可分享单个角色配置文件<br>
7. 个性化设置<br>
外观定制：<br>
更换聊天背景<br>
自定义气泡背景图片<br>
调整气泡宽度<br>
修改用户头像和昵称<br>
聊天设置：<br>
上下文消息数量限制<br>
图片是否计入上下文<br>
启用/禁用各类功能开关<br>
以及<br>
纯 HTML + CSS + JavaScript (单文件)<br>
🎯 适用场景<br>
角色扮演爱好者：与虚拟角色进行沉浸式对话<br>
创意写作：借助 AI 角色激发创作灵感<br>
情感陪伴：打造个性化的 AI 伴侣<br>
学习实验：研究 prompt engineering 和 RAG 技术<br>
本地化部署：无需服务器，开箱即用<br>
🔐 隐私与安全<br>
✅ 所有数据存储在本地浏览器<br>
✅ 不依赖任何后端服务<br>
✅ API Key 仅保存在用户本地<br>
⚠️ 需注意：localStorage 数据会随浏览器清除而丢失，建议定期导出备份<br>
