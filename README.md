## 📖 项目简介

My SWv114514 是一个单页面聊天应用，采用纯前端技术栈（HTML/CSS/JavaScript）构建。

为什么叫 v114514？因为开发者说这是"恶臭版本"，但我觉得更像是"一一四五，一四一四，就像你敲代码时的节奏"。🥁

应用提供类似即时通讯软件的界面体验，支持多角色对话、好友分组、聊天记录管理等功能。唯一的缺点是，这里的角色可能比你前任还难约出来聊天——哦等等，它们其实是 AI，秒回的！😏

## ✨ 主要功能

### 聊天功能
- 💬 **实时消息发送与接收**：比你的快递还快，而且不会丢件（除非你删了 localStorage）
- 🎭 **多角色扮演对话**：内置多个崩坏：星穹铁道、绝区零等游戏角色。想知道银狼会不会黑进你的冰箱？来试试！
- 📝 **Markdown 消息渲染支持**：支持 Markdown，这样你就可以用 `**粗体**` 来强调你有多饿
- 🖼️ **图片上传与显示**：可以发图片，但不能发你的作业答案（遗憾）
- 😊 **表情选择器**：丰富的表情，总有一个能表达你看到 bug 时的心情
- 📋 **剪贴板功能**：复制粘贴，程序员的第三只手

### 社交功能
- 👥 **好友管理系统**：管理你的虚拟好友，毕竟真人朋友太难找了
- 📁 **好友分组功能**：把角色分门别类，就像把你的袜子按颜色分类一样有意义
- 🏷️ **自定义显示名称**：你可以把"三月七"改成"我的债主"，她不会介意的
- 🎨 **文本生成头像**：自动生成头像，拯救手残党，再也不用担心画不出好看的圆圈了

### 界面特性
- 🌙 **深色主题设计**：保护你的眼睛，让你在熬夜写代码时看起来更像黑客
- 📱 **响应式布局**：手机电脑都能用，随时随地摸鱼
- 🖼️ **自定义聊天背景**：换上你喜欢的背景，假装你在马尔代夫度假
- 🎯 **侧边栏导航**：丝滑的侧边栏，比德芙还丝滑
- 🔔 **Toast 浮动提示**：提示会像吐司一样弹出来，但不能吃

## 🚀 快速开始

### 方式一：直接打开
直接在浏览器中打开 `index.html` 文件即可使用。

```bash
# 使用任意静态服务器
python -m http.server 8000
# 或使用 node
npx serve
```

然后在浏览器访问 `http://localhost:8000`

如果打不开，请检查：
1. 你是否打开了正确的文件
2. 你的浏览器是否还活着

## ⚙️ 配置说明

### CSS 变量
项目在 `:root` 中定义了完整的设计系统变量：
- 颜色方案：背景色、文字色、强调色，调色盘本盘
- 间距系统：让元素之间保持"社交距离"
- 圆角大小：圆一点，可爱一点
- 过渡动画：让变化不那么突兀，就像人生需要缓冲
- 字体设置：字好看，心情好

### 角色配置
内置角色配置集中维护在 `characters.js`，每个角色包含：
- Prompt 提示词：角色的"人格"，决定了她是高冷还是逗比
- 头像 URL：角色的"脸"，虽然都是二次元
- 默认显示名称：角色的"名字"，别叫错了
- 可选开场白：角色的"第一句话"，第一印象很重要

## 🎨 自定义

### 添加新角色
在 `characters.js` 中添加新的角色提示词、头像 URL，并把角色条目加入 `defaultFriendsData`：
```javascript
const NEW_CHARACTER_PROMPT = `# 角色描述...`;
const NEW_CHARACTER_AVATAR = "avatar_url";

const defaultFriendsData = {
  // ...
  new_character: {
    name: '新角色',
    avatar: NEW_CHARACTER_AVATAR,
    systemPrompt: NEW_CHARACTER_PROMPT,
    isCustom: false
  }
};
```

温馨提示：加太多角色可能会导致选择困难症发作。

### 修改主题
调整 CSS 变量即可更改主题配色：
```css
:root {
    --bg-primary: #你的背景色;
    --accent-gold: #你的强调色;
}
```

换个颜色，换个心情，说不定代码 bug 就少了（并不会）。

## 📝 使用说明

1. **开始对话**：点击左侧边栏的角色头像开始对话，就像敲门一样，不过不用等"谁啊"
2. **发送消息**：在底部输入框输入消息，点击发送按钮或按 Enter 键，Enter 键比按钮好用，真的
3. **切换视图**：使用顶部按钮切换聊天/列表视图，左眼右眼，哦不是，是这个那个
4. **系统设置**：点击右上角齿轮图标进行设置，齿轮转动，知识进入大脑
5. **清空聊天**：点击垃圾桶图标清空当前聊天记录，忘掉尴尬的对话，重新开始

## ⚠️ 注意事项

- 本应用为纯前端应用，聊天记录存储在本地，所以别清缓存，不然你的"甜言蜜语"就没了
- 部分功能可能需要网络连接（如 CDN 资源、外部图片），没网的时候，应用会像个断网的手机——什么都干不了
- 建议使用现代浏览器（Chrome、Firefox、Edge 等），IE 用户请自觉面壁思过
