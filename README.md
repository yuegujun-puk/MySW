# My SW

> 一个完全运行在浏览器本地的 AI 角色聊天应用 —— 所有数据（聊天记录、角色、自定义内容）都保存在你的设备上，不会上传到任何服务器。

## 📖 简介

**My SW** 是一个功能丰富的 AI 角色扮演聊天应用，对标酒馆（SillyTavern）生态，但开箱即用、纯前端运行。支持 OpenAI / Claude / Gemini 三种接口协议，可对接官方 API、中转站或本地部署模型。

**隐私优先**：API Key 仅保存在你当前浏览器的 `localStorage` 中，请求直接从浏览器发往服务方，不经过本站任何服务器（本站也没有服务器）。清除浏览器数据会一并清除，请定期导出备份。

> ⚠️ 使用 MySW 的代价是变成猫娘哦～

## ✨ 核心特性

### 聊天与角色扮演
- **单聊 / 群聊**：AI 群聊按活跃度与群节奏自然接话，被 @ 优先回复
- **角色卡市场**：集中管理内置 / 自制 / 市场角色，支持分组与批量操作
- **对话线程**：同一角色可拥有多条独立存档，剧情、变量、世界书互不干扰
- **语C 模式**：你来演一个角色，AI 演它自己，两人对戏
- **消息滑动**：同一条回复最多保留 12 个版本，随时切换
- **多开场白**：从主开场白 + 备用开场白中随机抽取
- **视觉小说模式（Galgame）**：立绘 + 背景 + 打字机 + 情绪识别，支持全屏舞台与 Live2D
- **世界书**：蓝灯常驻 / 绿灯关键词触发，支持递归、概率、冷却、延迟等高级规则
- **变量与状态栏**：HP / 金币 / 好感度等状态实时显示，AI 可读写变量
- **长期记忆 / 知识库 / 对话摘要**：让角色真正「记得住」
- **主动关怀 / 上线问候**：角色会主动找你说话

### 扩展与实验室
- **插件系统**：JS 插件，8 项细粒度权限，支持 ZIP 包与资源文件
- **正则脚本 / 消息脚本**：在对话链路的六个位置自动替换
- **聊天翻译**：11 种目标语言，AI / Google / DeepL 等多引擎
- **提示词预设**：三层可编辑文本，支持条件块与多套切换
- **聊天检查点与分叉**：任意消息处拍快照，探索不同剧情走向
- **聊天向量记忆**：语义检索历史片段，自动注入上下文
- **数据银行**：按全局 / 角色 / 聊天三级作用域装载参考资料
- **AI 图像生成**：支持 Pollinations / OpenAI / Hugging Face / SD WebUI
- **GAL 工作室**：节点式剧本编辑器，导出单文件 HTML 视觉小说
- **小游戏**：五子棋、围棋、谁是卧底、狼人杀、森林冰火人
- **学习辅导**：拍题讲解，三种模式 + 错题本 + 学习档案
- **声音工坊**：TTS 音色克隆与音高调节（MiniMax 等）
- **广告跳跳乐**：模拟广告体验（纯属整活，不接任何广告联盟）

### 数据与兼容
- **酒馆（SillyTavern）互通**：角色卡 V1/V2/V3、世界书、预设、聊天记录、整包备份均可导入
- **DeepSeek 导出包导入**：把整段历史搬过来
- **粘贴文本导入对话**：从任意来源粘进来的文字变成本站对话
- **导出视觉小说**：把当前对话导出成可离线打开的 Galgame 页面
- **自动备份**：关闭 / 刷新前自动导出 JSON
- **存储使用情况**：明细到条目，区分「可再生 / 不可再生」
- **PWA / 离线**：可添加到主屏幕，支持 Service Worker 离线访问历史记录

## 🚀 快速开始（5 分钟）

### 第 1 步：注册 API 平台并充值

推荐从以下平台开始（注册简单、支持支付宝 / 微信）：

| 平台 | 地址 | 特点 |
|---|---|---|
| DeepSeek 官方 | `https://api.deepseek.com` | 国内直连、最便宜 |
| 硅基流动 SiliconFlow | `https://api.siliconflow.cn` | 一个 Key 调上百款模型，新用户送额度 |
| 阿里百炼 / 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 新账号有免费额度 |
| OpenRouter | `https://openrouter.ai/api/v1` | 海外聚合，免注册即用 |

### 第 2 步：创建 API Key

进入平台的「API Keys」页面 → 点击「Create new key」→ 复制以 `sk-` 开头的那串字符。

> 🔒 **安全提示**：永远不要把 API Key 截图发到公开场合。怀疑泄露时第一时间去平台作废并生成新的。

### 第 3 步：回到本应用配置

1. 点右下角齿轮 ⚙️ → 「AI 配置」标签
2. 填入 **API 地址**、**API Key**、**模型名称**
3. 点「测试连接」→ 看到 ✅ 连接成功
4. 点「保存设置」大功告成

### 第 4 步：开始聊天

回到聊天界面，点左侧任意角色头像进入对话，直接在底部输入框打字发送即可。

> 💡 **找设置项更快**：设置弹窗顶部有搜索框，输入「Key」「温度」「气泡」等关键词可直接跳转。

## 🔧 核心配置说明

### API 地址填写

支持三种接口协议，填到域名部分即可，路径由系统按协议自动补全：

| 协议 | 地址示例 | 认证方式 |
|---|---|---|
| OpenAI 兼容 | `https://api.deepseek.com` | `Authorization: Bearer` |
| Claude | `https://api.anthropic.com` | `x-api-key` + `anthropic-version` |
| Gemini | `https://generativelanguage.googleapis.com` | `x-goog-api-key` |

「接口协议」一般留「自动识别」即可：地址含 `/v1/messages` 判为 Claude，含 `:generateContent` 或 `/v1beta/models/` 判为 Gemini，其余按 OpenAI 兼容处理。

### 生成参数（新手保持默认）

- **随机性 (temperature)**：0~2，越大越有创造性，角色扮演建议 0.8~1.2
- **核采样 (topP)**：0~1，默认 0.9
- **思考强度**：越高想得越久、答案越稳、也更慢更贵
- **最大上下文**：AI 能「记住」的历史轮数，太小会失忆，太大会更贵
- **单条回复上限**：限制 AI 单次回复长度

### 别凭印象填模型名

厂商随时会换模型 ID。填之前先点一次「获取模型」，从真实列表里挑。名字填错的表现通常是 `404 model not found`，不是 Key 的问题。

## 💾 数据管理

### 存储模型

本应用的数据分布在两类浏览器存储中：

| 存储 | 存什么 | 特点 |
|---|---|---|
| **localStorage** | 设置、API Key、插件源码与参数、最近聊天镜像、论坛数据（`myswForumData`）、广告配置等 | 每个站点只有几 MB，写满后连几 KB 都存不进去 |
| **IndexedDB** | 完整聊天记录、角色数据、知识库、实验室数据、论坛独立库、启动画面素材、插件 ZIP 资源等 | 容量大得多，是主存储 |

此外还有 **Cache Storage**（Service Worker 离线资源）。

### 查看存储使用情况

位置在「设置 → 导入导出」标签的导入导出按钮下方：点「查看存储使用情况」打开面板明细；边上的「重新统计」只重算体积、不重建面板，所以不会把你已经勾选的项清掉。

- **一眼看总量**：顶部进度条与四张卡片给出「浏览器统计的总占用 / 本站可用配额 / IndexedDB 合计 / localStorage 合计」，以及 Cache Storage 占了多少。
- **按用途分列**：下面按库分组列出 localStorage、主数据库 `MySW_Storage`，以及知识库 / 实验室 / 论坛 / 启动画面等独立 IndexedDB 库，每个库再展开到具体条目，条目同时给出「存了哪些 key」。
- **标出「可再生」与「不可再生」**：聊天记录、角色数据、论坛内容、知识库这类删了就回不来的条目会打上红色的「不可再生」标签；提示词分块缓存、折叠状态、商店缓存这类随时能重建的才是「可再生」。
- **两道确认，删不掉聊天记录**：勾选条目后点「清理选中」，可再生项只要确认一次；只要列表里含不可再生项，就必须在弹出的框里手动输入 `DELETE` 才会执行，防止顺手把聊天记录清空。想更保险，可以先把「导出全部数据」存一份再动手。
- **一键清理可再生数据**：一次清掉所有「可再生」条目并顺带清空 Service Worker 缓存刷新页面，绝不会碰不可再生条目。

> ⚠️ 清理可再生项时，**Cache Storage 与 IndexedDB 中的可再生条目会一起被清理**，但聊天记录、角色、论坛内容、知识库等不可再生数据不会被碰。

### 关于浏览器存储

- ❌ **清除浏览器数据 = 数据全失**。请定期导出备份！
- ❌ 不同浏览器、不同设备、不同浏览器配置文件之间数据不互通。
- ✅ 隐身模式下数据不保留（这是浏览器的特性）。
- 💡 聊天记录超过约 120 万字符后，localStorage 里只保留最近十几条的镜像，完整记录依然在 IndexedDB 中，导出和继续聊天都不受影响。

### 导出 / 导入 / 自动备份

在「设置 → 导入导出」标签中：

- **导出设置**：只导出 AI 配置、界面设置等，体积小，适合分享配置模板。
- **导出全部数据**：完整备份（包含聊天记录、角色、知识库等），换设备必用。
- **导入数据**：恢复备份，可选「合并」或「覆盖」。
- **自动备份**：默认开启。关闭网页或刷新前自动导出 JSON 文件到下载目录；默认 30 分钟内最多一次，可在旁边改成 1～1440 分钟。不想自动下载时可以取消勾选。

## 🔌 插件开发速览

插件是一个 JavaScript 文件，通过全局对象 `window.MySWPlugins.register()` 注册。导入的插件默认跑在受限沙箱里，权限需显式授权。

```javascript
// hello-plugin.js
MySWPlugins.register({
  id: 'hello-shout',
  name: '喊话器',
  description: '把你发出的每条消息都变成全大写并在结尾加感叹号。',
  permissions: [],  // 纯文本变换，不需要权限
  params: [
    { key: 'mark', label: '结尾标记', type: 'text', value: '！' }
  ],
  transformText(text, params) {
    const mark = String(params.mark || '！');
    const upper = String(text || '').toUpperCase();
    return upper.endsWith(mark) ? upper : upper + mark;
  }
});
```

**四种钩子**：`activate`（启用）、`deactivate`（停用）、`transformText`（改写用户文本）、`transformPrompt`（改写系统提示词）。

**八项权限**：`ui` / `dom` / `chatRead` / `chatWrite` / `storage` / `api` / `network` / `download`。权限面板里开总闸，再在插件卡片上单独授权（AND 关系）。

## ❓ 常见问题

<details>
<summary><b>Q1：填写完 Key 还是提示「请先配置 API」？</b></summary>

检查是否点过「保存设置」（不是「测试连接」）。如仍报错，刷新页面重试。
</details>

<details>
<summary><b>Q2：AI 回复到一半就断了？</b></summary>

通常是触发了 maxTokens 上限。在设置里调大「单条回复上限」。
</details>

<details>
<summary><b>Q3：AI 经常「失忆」？</b></summary>

调大「最大上下文轮数」。注意：上下文越大，Token 消耗越多、费用越高。更好的组合是「上下文轮数 + 对话摘要 + 世界书 + 长期记忆」。
</details>

<details>
<summary><b>Q4：测试连接报「模型不存在 / 404」？</b></summary>

多半不是 Key 坏了，是模型名过期。点「获取模型」从真实列表里选一个，别照旧教程抄名字。如果「获取模型」也报错，才是 Key / 地址 / 网络的问题。
</details>

<details>
<summary><b>Q5：提示「设置没能保存 / 本地存储已满」？</b></summary>

浏览器的存储分为两类：**localStorage**（几 MB，存设置、API Key 和最近消息镜像）和 **IndexedDB**（存完整聊天记录、角色、知识库、论坛、实验室数据等，容量大得多）。localStorage 存满后，连几 KB 的 API Key 都写不进去，表现就是“填好、点保存、关掉再打开又空了”。

现在的版本会在保存失败时明确告诉你哪几项没存上，并给一个「去清理」入口：到存储面板勾选「只选可再生项」——这会清理 **Cache Storage 和 IndexedDB 中的可再生条目**（提示词分块缓存、折叠状态、商店缓存、缩略图等），**不会删除聊天记录、角色、知识库、论坛内容等不可再生数据**。清完再点一次保存即可。

另外，聊天记录超过约 120 万字符后，localStorage 里只保留最近十几条的镜像，完整记录依然在 IndexedDB 中，导出和继续聊天都不受影响。
</details>

<details>
<summary><b>Q6：AI 老是叫错我的名字，或把我当成两个人？</b></summary>

① 改完昵称后开一条新对话，或到「设置 → 聊天设置 → 上下文与记忆」关掉「把『我的昵称』发给 AI」。② 语C 时昵称与所演角色不一致，提示词里会同时出现「用户叫 A」和「用户在演 B」，详见语C 章节。
</details>

<details>
<summary><b>Q7：如何在手机上使用？</b></summary>

可「添加到主屏幕」当 App 用，支持 Service Worker 离线访问历史记录。手机视图 / 桌面视图可切换。
</details>

<details>
<summary><b>Q8：AI 会把我的对话拿去训练吗？</b></summary>

取决于你使用的 API 平台。多数付费 API 平台明确表示不会用你的 API 调用数据训练模型（详见各平台隐私政策）。本应用本身是纯前端应用，不可能收集你的数据。
</details>

<details>
<summary><b>Q9：我写的插件为什么不生效？</b></summary>

按顺序检查：① 插件卡片上的「启用」是否勾上；② 卡片上有没有黄色提示条（权限没给全）；③ 控制台有没有 `[插件名] xxx 失败` 的警告；④ id 是否与已有插件重复。详见插件编写指南。
</details>

<details>
<summary><b>Q10：论坛数据能备份吗？换设备怎么带过去？</b></summary>

可以。论坛右侧栏有「导出论坛数据 / 导入论坛数据」，导出为包含帖子、评论、私信、关注、收藏与分区设置的 JSON。导入时可选「合并」（按 id 去重后追加）或「覆盖」。合并导入会保留互动数更多的版本，不会把点赞清零。
</details>

## 🔐 安全与隐私

- **数据本地化**：所有数据存于浏览器 `localStorage` / `IndexedDB`，不上传服务器
- **Key 不落服务端**：API Key 只存在你的浏览器，请求直接从你的浏览器发往服务方
- **插件沙箱**：导入的插件默认拿不到 `document`、`window`、`localStorage`、`fetch`，只能用受控通道
- **中转站风险**：使用第三方中转站时，对话内容与 Key 会经过第三方服务器，价格异常低廉时要警惕跑路风险
- **浏览器存储边界**：清除浏览器数据 = 数据全失；不同浏览器 / 设备 / 配置文件之间数据不互通；隐身模式下数据不保留
- **同设备风险**：同一台设备上能打开这个页面的人，也能在开发者工具里看到你的 Key
